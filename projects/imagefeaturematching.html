Image feature Matching

Project Summary

Programming Language: Python

Libraries/Frameworks: cv2, matplotlib, and numpy
Source Code is not public due to SFU policy

Project Description

This project implements a complete feature-based image alignment and augmented reality pipeline using classical computer vision techniques. The goal was to detect keypoints, match features, compute homographies, and use them to perform perspective warping. Ultimately overlaying one visual element (a book cover or video) onto another in a realistic perspective

Feature Detection and Matching Overview

The feature detection uses FAST detectors for keypoint detection. The keypoints are then used to extract BRIEF descriptors to describe image patches. The descriptors are then used to find matching points in two images using a Brute-Force matcher and KNN (K-Nearest Neighbors)

Homography Estimation

The Homography Estimation creates a transformation matrix that best fits the observed transformations of thematched points. The points are first normalized to imporve the quality of the Homography Matrix. The Homography Matrix is computed useing Singular Value Decomposition (SVD)

RANSAC

The RANSAC implementation uses 4 random points in each pass to calculate the homography and counts the number of inliers (matches that fall within the allowed error margin) and choses the best homography. This limits the influence of mismatches by eliminating them from the homography calculation.
