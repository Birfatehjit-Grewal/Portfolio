Dynamic Analysis

Project Summary

Programming Language: C++

Libraries/Frameworks: LLVM
Source Code

Project Description

This project implements a dynamic fault-tolerant analysis for C/C++ programs by instrumenting LLVM IR with runtime safety checks. The goal is to detect and mitigate common memory and arithmetic errors—such as invalid pointer accesses, invalid frees, and divide-by-zero operations—while maintaining program availability under different quality-of-service (QoS) policies.

Errors Handled

This instrumentation is not all inclusive and only handles the following errors.
  • Error: Invalid read from memory
  • Error: Invalid write to memory
  • Error: Invalid free of memory
  • Error: Division by zero

Limitations

This instrumentation limitations are listed below.
  • Assumed that all heap memory will be allocated via a call to malloc().
  • Assumed allocated heap memory will only be freed via a call to free()

Implementation

The implementation for the error handleing is seperated into 4 parts. Depending on which flag is used to run the program.
  • Base
  • -ignore
  • -defaults
  • -returns

Base

The base implementation for the error handleing logs the error into terminal and exits the program. The memory errors are tracked useing Shadow Memory to keep track of memory allocations for both spatial and temporal safety. The logging can result in the following outputs.
  • Found: Invalid read from memory
  • Found: Invalid write to memory
  • Found: Invalid free of memory
  • Found: Division by zero

Ignore

The ignore implementation for the error handleing builds off the base implementation. Instead of exiting when encountering the Invalid write to memory and Invalid free of memory the instructions are skipped allowing the program to continue running. This is possible because freeing memory that has not been allocated or writing to memory that is not valid can be skipped without consequences since they don't return any values.

Defaults

The defaults implementation for the error handleing builds off the Ignore implementation. Instead of exiting when encountering the Invalid read from memory and Division by zero we instead replace there return value with a default 0 allowing the program to continue running eventhough its values might not be correct.

Returns

The Returns implementation for the error handleing builds off the Base implementation. Where instead of exiting when encountering the errors we instead return the entire function with a default value depending on the return type of the function.
