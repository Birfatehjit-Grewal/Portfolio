Project Description

This project implements a static dataflow analysis using the Soot framework to analyze Java bytecode. The analysis targets a custom Kitten API that encodes object behavior through a protocol-like finite state machine, where method calls cause state transitions. Incorrect method usage can result in invalid state transitions (ex. calling pet() while a kitten is already playing). The analysis is intraprocedural and conservatively tracks the possible states of kitten variables across program control flow. It reports potential protocol violations using a KittenErrorReporter, including the variable name, source line, target state, and invalid source state.

Kitten API overview

Individual methods of the kitten API attempt to transition a kitten into a specific state, and it is invalid to transition from some states into other states. The valid and invalid semantics are captured by the table below.
